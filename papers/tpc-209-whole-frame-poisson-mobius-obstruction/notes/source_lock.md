## Exact scope of the new derivation

The Poisson theorem is proved for Schwartz component functions (F_D) with
((D,q)=1).  It is an exact interface theorem.  Extending the actual discrete
Möbius/hybrid packets to a canonical smooth family, carrying nonunit rows, and
preserving the diagonal subtraction are future obligations.

## External source boundary

The current source lock contains Harper's general-sequence BDH architecture,
Blomer--Pascadi's post-emitter fixed-modulus Kloosterman theorem, and Pascadi's
post-emitter sparse-Fourier machinery.  None of these sources supplies the
profile-aware conversion of the TPC-209 expression to a prime-only,
diagonal-corrected, block-reassembled Kloosterman family.

No external theorem is used to prove the TPC-209 identities; the analytic
Poisson step, finite graph algebra, multiplicative Fourier diagonalization,
and Gauss crosswalk are proved directly.
