# RH-157: Spectral-Reset Cross-Action Cancellation

For a full-memory spectral projector `P` and `M=R+T`, RH-157 proves the exact
identity

`(I-P) R P = -(I-P) T P`.

Thus the old projected-cross action sees only tail coupling, not the positive
native recent Gram from RH-156.  Fifty tail-inactive snapshots have exactly
zero cross action.  Of 80 active snapshots, outward packet/tail balls certify
a positive fourth coupling singular value on only 54; the terminal-half
count is 30/62.  The native reset support therefore cannot be identified
directly with the old directional cross-action support.
