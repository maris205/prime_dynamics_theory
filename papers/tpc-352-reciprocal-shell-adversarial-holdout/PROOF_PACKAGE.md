## Exact statements

zero sum.  The associated incidence vector is the exact linear combination of
the divisibility indicators, including all multiply-divisible positions.  For
every finite defect matrix, bilinearity gives the reciprocal incidence Gram
expansion.  If the incidence vector is nonzero, the normalized vector is a
valid test vector for the induced Euclidean norm, proving the lower-witness
inequality.

These are `PROVED_EXACT_FINITE` statements in the declared literal model.
