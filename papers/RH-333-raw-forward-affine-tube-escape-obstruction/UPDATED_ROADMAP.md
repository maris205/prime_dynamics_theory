# Roadmap after RH-333

RH-333 closes the first admissible RH-333 test with a rigorous scoped
negative result.  The canonical raw mass-one full-line forward affine tube
cannot approximate the physical retained path at `O(k*sigma)` or `o(H_k)` on
fixed-phase sequences, or uniformly in one compact first-alias phase window:
before the final tiny closing component row, an early innovation has width
comparable to the entire physical chart and leaves a strictly positive escape
gap.

The failed object is exact and narrow:

```text
raw full-line affine rows
    + arbitrary entrance independent of innovations
    + k-1 component-row prefix
    + retained preclosing coordinate.
```

The result does not prove endpoint failure after the closing row and does not
rule out a cyclic bridge, Doob transform, physical truncated/folded affine
kernel, adapted reference, or branch-complete nonlinear closing profile.
Those alternatives remain undefined in one common physical data type and are
therefore `NOT_TESTABLE`, not negative theorems.

The positive full-boundary-cycle route can reopen only after a replacement
reference is defined before comparison and all of the following are proved:

1. mass-one normalization on the exact physical charts;
2. a common entrance law and innovation coupling through all component rows;
3. treatment of the tiny closing row without discarding the preclosing escape;
4. phase-uniform moment/support control on the natural clock; and
5. a retained-path comparison in one declared data type.

Independently, the planned RH-334 gauge-fixed physical first-alias observation
map may still be investigated.  RH-333 supplies no positive all-leg
probability transport to feed a trace Duhamel theorem, so RH-335/RH-336 cannot
activate through the raw affine route.  Any continuation must either define
and validate an adapted physical reference or carry the RH-333 obstruction as
an explicit failed bridge hypothesis.

Probability retained paths remain distinct from cyclic traces.  Physical
trace observation, signed parity/shell cancellation, target-scale
parity/alias replacement, signed far control, off-alias vanishing, and
head/counterloop determinant gluing all remain open.  Finite rows are
reproduction checks only; Gates A--E remain false/open.
