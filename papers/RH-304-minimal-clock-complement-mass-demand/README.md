    M >= (1-theta) q^2 (q_star/q)^n / (1+lambda^(-n)).

`0.9468615163684616`, leaving only `0.05313848363153839` below the archived
`sigma^(-1)` cap.  This is conditional on relative moving-order matching;
that matching is not proved.
