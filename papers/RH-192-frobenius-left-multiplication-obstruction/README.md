# RH-192: Frobenius Left-Multiplication Obstruction

The physical matrix state has shape `n x m`, while its evolution is only
left multiplication, `X -> A X`.  Column-major vectorization therefore gives
`I_m tensor A`, not a new simple-spectrum operator.  Consequently

```text
det(zI - L_A) = det(zI - A)^m,
rank P_Gamma(L_A) = m rank P_Gamma(A).
```

This makes a literal rank-one or rank-four Riesz shell in the full Frobenius
space impossible for the RH-185 widths `m=64,128,256`.  If one packet root
matches one base eigenvalue, the Feshbach complement must carry `m-1`
additional copies.  The 126-window, 416-root audit finds zero
complement-free compatible cases; the rootwise burden ranges from 63 to 255.

The result corrects the state type, not the spectral observation.  A
source-cyclic invariant subspace generated by the single matrix seed need
not inherit the factor `m`; that quotient is the next paper.  No claim about
Gate A, Hilbert--Pólya, zeta zeros, or RH is made.
