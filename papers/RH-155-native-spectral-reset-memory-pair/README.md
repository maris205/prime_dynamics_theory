# RH-155: Native Spectral-Reset Memory Pair

RH-155 constructs the recent Gram and old memory tail directly on each
clock-rank spectral reset packet.  A universal geometric tail-mass bound and
the reset packet's selected-eigenvalue lower give the sharp certificate

`D <= tau / (lambda_r - tau) R`.

All 130 frozen snapshots certify with ratio below one.  The maximum upper is
`0.224696`, the minimum selected-eigenvalue-to-twice-tail margin is `2.72523`,
and all 62 RH-154 terminal-half snapshots also certify.  This closes a native
memory pair, not yet the older directional cross-action support functional.
