# TPC-348 computational protocol

The producer locks the TPC-347 producer and certificate.  It reconstructs the
same physical, ideal, and defect matrices on two origins, three source counts,
four shell anchors, two kernel exponents, and four sign laws.

For each row, the mask-hit set is computed from the interval and active shell
only.  The first hit and the maximum hit-column norm are both retained.  The
maximum is the deterministic functional

```text
W_I(D)=max_{t in J_I} ||D e_t||_2.
```

The producer also evaluates the exact two-sided projection formula for the
selected column.  The independent checker reverses shell accumulation order,
rebuilds all matrices without importing the producer, checks every stored row,
and recomputes the rational anchor.  The stress suite targets selector,
left/right mask, anchor, census, and firewall mutations.

All numerical rows are finite audits.  No file is used as evidence for a
source-uniform arithmetic estimate.
