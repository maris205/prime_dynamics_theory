\begin{theorem}[Multiplicativity firewall]
The function \(c\) is not multiplicative.  In particular,
\[
 c(3)=1,\qquad c(5)=1,\qquad c(15)=-1,
\]
although \((3,5)=1\).
\end{theorem}
\begin{proof}
Using
\(\mu(3)=\mu(5)=\mu(7)=\mu(17)=-1\) and
\(\mu(15)=1\), the three values are immediate.  Thus
\(c(15)\ne c(3)c(5)\).
\end{proof}
