# RH-158: Adaptive-Lag Reset Cross Bridge

RH-158 proves that lag exposes the recent innovations hidden by the exact
contemporaneous cancellation.  It also sharpens the projector-motion radius
from `2 ||R|| epsilon` to the shift-invariant and asymptotically sharp
`spectral_spread(R) epsilon`.

An outward audit evaluates 694 lag candidates over 120 update targets.  A
deterministic best-base choice among lags at most eight certifies a positive
fourth cross singular value at all 120 targets, all 62 delayed-half targets,
and all 10 terminals.  The smallest normalized base is
`2.587419843e-14`; this is a complete finite bridge, not an all-level
bounded-lag theorem.
