# RH-257: Monodromy Integrality Barrier for Signed Moment Fits

Arbitrary real signed weights fit the order-2--12 expanded shell moments within
tolerance at all 32 endpoints.  This apparent success is not a determinant
selector: every fit has fractional weights, maximum weights range from
`39.6394` to `3.02234e11`, and the corresponding local product has nontrivial
monodromy.

The exact theorem is elementary but decisive.  For distinct roots `lambda_j`,
the germ generated by moments `sum_j w_j lambda_j^n` is
`prod_j (1-lambda_j z)^{w_j}`.  It is single-valued meromorphic around each
reciprocal root only if the combined exponent is an integer.  Thus arbitrary
fractional signed least squares is not a legal determinant quotient.

Gates A--E remain false/open.  No Hilbert--Polya operator, zeta-divisor
equality, Riemann-zero identification, or RH implication is claimed.
