# TPC-390 paper plan

## Research question

Does the finite slope interface transferred through TPC-389 remain predictive
under a second recursive composition, from `N=1024` through `N=1280` to a
fresh `N=1536` holdout layer?

## Claim-sized contributions

1. A predeclared fourth coordinate-disjoint origin family and a three-level
   count panel.
2. A frozen TPC-389 parent interface tested without current-family refitting.
3. Separate one-step, local-control, and two-step recursive forecasts.
4. An exact finite composition identity check, independent descending-shell
   replay, mutation firewall, and complete PDF/provenance package.
5. A scoped finite obstruction if recursive error crosses the predeclared cap.

## Locked hypotheses

* H1: one-step parent transfer from `1280` to `1536` is within the 3% cap.
* H2: the current-family `1024 -> 1280` slope is a useful local control.
* H3: two-step application of the frozen parent slope remains within the same
  cap.
* H4: recursive success or failure does not repair the inherited spectral
  diagnostic or pay arithmetic credit.

H1--H4 are finite-panel statements only.  Any failed H3 is retained as an
obstruction rather than converted into a theorem by post-hoc choices.

## Follow-up rule

If H3 survives, the next question is a fresh-family replication at the same
recursive depth.  If H3 fails, the next question localizes the failure by
`Q`, band, law, and normalization while freezing the failed horizon.  In both
branches, source-valid growing control and arithmetic `L2` remain open.
