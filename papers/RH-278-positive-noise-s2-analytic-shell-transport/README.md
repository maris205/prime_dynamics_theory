# RH-278: Positive-noise S2 shell transport

On every compact interval strictly inside `(0,infinity)`, the normalized
folded Gaussian kernel is an analytic Hilbert--Schmidt family.  Any exact
spectral shell isolated at one positive noise therefore has a local common
contour and an explicit Neumann resolvent bound.  If the shell contains all
eigenvalues outside a spectral-free radius `r<1`, its orthogonal quotient has
spectral radius below `r`, so some power is contractive and RH-269 activates
locally.

This is a positive-noise local theorem.  RH-276/RH-277 prevent its direct
extension to one fixed-rank zero-noise slab.
