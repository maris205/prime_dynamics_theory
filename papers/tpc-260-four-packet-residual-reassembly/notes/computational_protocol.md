# TPC-260 computational protocol

1. Reconstruct varied positive four-block sizes and verify all three weighted
   Haar norms, all pairwise orthogonalities, and the scaling complement with
   exact rational arithmetic.
2. Verify the TPC-258 null weights numerically only as a diagnostic; the
   scaling orthogonality is checked symbolically before those weights enter.
3. Build plus, alternating, and Gaussian fourth-root packet families and
   verify packet diagonals, DFT Parseval, mode-zero reconstruction, null
   projections, and residual endpoints.
4. Independently regenerate the same identities with different sizes and
   mutation records; reject changed phase, coefficient, or firewall claims.

No finite fixture is used as evidence for a growing prime-shell theorem.
