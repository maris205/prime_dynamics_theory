# TPC-301 computational protocol

1. Lock the TPC-299 producer/result and TPC-300 producer/result hashes.
2. Rebuild every physical shell and literal profile matrix from the source-first
   engine using exact rational entries before conversion to 60-digit arithmetic.
3. For each target and prefix, compute the least-squares residual ratio.
4. For each tau, select the first feasible weighted and positive prefixes.
5. Evaluate both targets at the common weighted prefix, at their own prefixes,
   and at the full available prefix.
6. Solve the active quadratic budget frontier by a monotone ridge-parameter
   bisection with 180 iterations.
7. Store outward decimal intervals for budgets, normalizers, ratios, and gaps.
8. Replay all rows in a producer-independent checker and run exact scalar
   stress fixtures in normal and optimized Python modes.

The finite target count is 219.  The inherited parent metadata retains a
separate 1,380-edge grid count; the release reports both fields explicitly.
No random sampling is used.
