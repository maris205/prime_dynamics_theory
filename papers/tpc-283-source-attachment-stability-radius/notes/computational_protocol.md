# TPC-283 computational protocol

The producer hash-locks TPC-282 code and canonical result, computes four exact
rational two-dimensional fixtures, and transfers all twelve parent intervals.
The independent checker recomputes each fixture and checks the radius thresholds
and row binding without importing the producer.  The stress checker mutates the
theorem, threshold, budget, provenance, fixture, and census fields.  Normal and
optimized runs must have empty stderr and identical stdout.
