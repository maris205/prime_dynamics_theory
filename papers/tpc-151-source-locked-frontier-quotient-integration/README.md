> Four-Map Completion, an Actual Mobius Core, and Split Endpoint

## Core result

TPC-143--146 refine the old frontier-totalization gap into one common
first object:

```text
H1.frontier_occurrence_lift = NOT_TESTABLE.
```

The lift is a conservative row-separated one-to-many sparse matrix
from every nonsoft cut path (`ELIGIBLE_TAIL_OPEN` and
`FRONTIER_UNMAPPED`) to fully typed downstream occurrences.  The
current sample has 2,988 frontier paths and no eligible-tail path, but
sample emptiness is not promoted to an asymptotic theorem.

The field-descent obstruction is likewise scoped: it concerns the
maximal formal completion class determined by the archived schema,
not impossibility on the unknown actual-support carrier.

The alternative scalar route is also kept exact: it requires both a
theorem proving the complete original frontier sum is `o(X)` and a
theorem-backed disposition of every eligible-tail-open path.  A
frontier scalar estimate alone does not totalize the all-nonsoft
carrier.

TPC-147--150 provide a genuine actual-core arithmetic result.  After
the quotient lift

```text
t = a D(z),   t + 2 = s V(z),
mu(D(z)) mu(V(z)) = G_a(t) G_s(t+2),
```

the small-polylog periodic core lies in the quantitative affine
almost-scale corridor.  This is classified as `L1_ACTUAL_CORE`, not
positive L2: actual physical weights, generic phases, deterministic
all-prefix control, and the complete four-sign return remain absent,
and the fixed-X-power exponent is zero.

The source-locked integration therefore remains assembled with gaps.
It proves neither frontier totalization nor a physical hard-packet
estimate.
