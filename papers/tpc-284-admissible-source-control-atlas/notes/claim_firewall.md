# TPC-284 claim firewall

`NUMERICALLY_CERTIFIED_FINITE` refers to the exact finite row set and the
hash-locked implementation named in the certificate.  It does not mean that
the six controls exhaust all literal source perturbations, nor that the row
set is an initial segment of an asymptotic schedule.

The eight sign flips are a scoped obstruction to a finite sign-stability
heuristic.  They are not a counterexample to the twin-prime conjecture and do
not negate the fact that all 72 tested rows remain nonzero.

```text
TPC284_CONTROL_ATLAS = NUMERICALLY_CERTIFIED_FINITE_72_ROWS
TPC284_SIGN_FLIP_OBSTRUCTION = NUMERICALLY_CERTIFIED_FINITE_8_FLIPS
TPC284_FULL_ADMISSIBLE_CLASS = OPEN
TPC284_ASYMPTOTIC_STABILITY = OPEN
TPC284_ARITHMETIC_L2 = OPEN_LITERAL_SOURCE
TPC284_FIXED_POWER_CREDIT = 0
TPC284_FULL_GATE_B = OPEN
TPC284_TWIN_PRIME_RESULT = NONE
```
