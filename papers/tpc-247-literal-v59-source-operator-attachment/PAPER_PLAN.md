# TPC-247 paper plan

## Question

Can the literal V59 Gate-B scalar itself be placed in a two-lane Hilbert
covariance without first assuming the still-open primitive-rational
coefficient attachment, and what exact norm toll does such a placement incur?

## Contribution

1. Freeze the V59 scalar as one finite source-index operator `A_x`.
2. Decompose it by disjoint coordinate support projections with every
   admissible `(q,t,u)` triple occurring exactly once.
3. Realize the block sum as one covariance in tagged external copies.
4. Prove exact output-lane duplication and a finite counterexample to
   input-lane norm preservation.
5. Separate this physical-index identity from TPC-243 primitive-frequency
   synthesis, TPC-244 common multipliers and every arithmetic gate.

## Claim boundary

The theorem is finite source algebra.  A hard disjoint partition is an exact
bookkeeping specialization, not V59's smooth bounded-overlap partition.  The
external representation is not norm-preserving and supplies no PSD Gram,
near-isometry, arithmetic cancellation, strict `1/400`, or twin-prime result.
