# RH-220: gauge-complete divisor reconstruction

Every raw conjugate quartet is reconstructed exactly from four intrinsic
coordinates: center `mu`, centered RMS radius `r`, and shape `(u,eta)`, via
`D(z)=r^4 Q((z-mu)/r)`.  All 32 physical endpoint coefficient vectors are
recovered with maximum error `7.8e-16`.  Shape alone is non-injective because
arbitrary centers and positive radii share the same quotient.  The next Gate-A
target is a rank-growing divisor retaining a global gauge ledger.
