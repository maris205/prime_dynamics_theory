# TPC-262 claim firewall

```text
PROVED = finite reduced-residue projection, literal signed remainder operator
         with deleted diagonal, weighted cross-Gram identity, four-point DFT,
         phase-character separation, and conditional endpoint criterion
NUMERICALLY_CERTIFIED = exact finite prime-shell operator-image witness
CONDITIONAL_THEOREM = endpoint conclusion if an effective saving >1/400 is supplied
OPEN = actual growing V59 beta/w character-specific cross-Gram estimate
REFUTED_SCOPED = diagonal/PSD-only promotion to a global saving
NOT_CLAIMED = growing-shell counterexample, arithmetic L2, fixed atom, Gate B,
              or twin-prime conclusion
```

The finite witness is built from the literal unit-class matrices, but its
packet inputs are freely chosen operator-image probes. They are not identified
with the source-frozen V59 `beta` and `w` sequences.
