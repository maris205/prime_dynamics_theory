## Recommended RH-192 target

Build a reproducible physical oblique-block dataset for the surviving local
windows and validate `zI-D` on predeclared root contours.  The certificate
must combine nominal inverse defects, contour mesh covering, floating-point
roundoff, and an outward operator ball.  Feed the resulting bound into the
exact product

```text
sup_Gamma ||(z-K)^{-1}|| ||(z-D)^{-1}|| ||B|| ||C|| < 1.
```

A failure would close the current local candidate at those contours; a
positive margin would justify the next finite Riesz-rank paper.  Neither
outcome by itself closes Gate A or any Hilbert--Polya downstream gate.

The finite rank paper must compute the complement count as well as the
packet count.  It may identify the full count with the packet count only if
the validated contour encloses no complement eigenvalues.
