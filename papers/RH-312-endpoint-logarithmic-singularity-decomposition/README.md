# RH-312: Endpoint logarithmic singularity decomposition

Let `q_star=(r_H lambda)^(-1)` and `rho_star=q_star^(-1)`.  The all-order
deterministic anchors satisfy the stronger endpoint identity

    -sum_(n>=2) a_n rho_star^n w^n/n
      = log(1-w) + w + H_reg(w),

where `H_reg` is analytic on a disk of radius strictly larger than one.  The
archived trace-block constant gives the explicit safe lower radius
`0.801254^(-1/6)=1.0376199142...`.

Thus the endpoint target has one universal logarithmic singularity plus a
strictly more regular deterministic remainder.  This is an all-order target
theorem, not endpoint convergence of the actual noisy complement.

Gates A--E remain false/open.
