\section{Claim boundary}
\label{sec:claim-boundary}

\subsection*{Unconditional finite identities}

\begin{itemize}[leftmargin=2em]
\item A branch \(\beta\) fixes \(j_\theta,\sigma_\theta\) and its
  phase multiplier, while
  \(u_{\beta,z}=U_\theta(\tau_\beta+B_\beta z)\) and
  \(m_{\beta,z}=M_\theta(\tau_\beta+B_\beta z)\) vary with \(z\).
\item The branch multiplier has the integer factorization
  \[
  \Omega_\beta/c_\beta
  =
  \kappa_\beta\ell_\beta v_\beta
  (\sigma_\beta/g_\beta).
  \]
  The stronger divisibility \(c\mid\ell vB\) is not inferred.
\item For every opened atom with \(q_X\nmid u_{\beta,z}\),
  \[
  \omega_\beta
  =
  A_{\beta,z}(m_{\beta,z}j_\theta+h_0)
  \quad\bmod q_X.
  \]
\item Exact resonance preimages use
  \(\mathsf H_\beta=H_q(\#I_\beta^\ast)\), never cell occupancy.
\item Every maximally literal fine cell is a singleton because its
  retained source data recover \(j\).  Cross-cell collisions satisfy
  \eqref{eq:correct-cross-congruence}.
\item The exact atom weights reassemble as
  \(w_\beta=\sum_z w_{\beta,z}\), recovering the TPC-99 census and
  centered-energy decomposition without duplication.
\end{itemize}

These are \(\Lzero\) statements once the upstream native formulas
and source inverse are supplied.

\subsection*{Conditional literal return}

Assuming the TPC-93--TPC-98 lossless source reconstruction,
row-\(\ell^1\) bounds, divisor and projector envelopes, actual masks,
and one global normalization, the opened nonconstant submass
\[
 q_X\mid U_\theta(\tau_\beta+B_\beta z)
\]
is \(O(X^{o(1)}Q_X^2)\).  This one-subledger return and the exact
TPC-99 atom crosswalk are \(\Lone\) progress.

The construction retains:
\begin{itemize}[leftmargin=2em]
\item the complete \(\beta=(\theta,c,\kappa)\) and \(z\) labels;
\item \(b,c,\kappa,g,B\), \(I_\beta^\ast,N_\beta,\mathsf H_\beta\);
\item the TPC-93 child-to-source inverse, actual source row pair,
  opened value \(u_{\beta,z}\), row-gcd child, and masks;
\item both polarizations and \(\varepsilon_\theta\);
\item the external frequency ledger, which separately retains the
  least-absolute lift \(\widetilde r\), signed reconstruction
  multiplier, and modulus \(cq_X\); and
\item the original branch weight and global normalization.
\end{itemize}

\subsection*{Not proved}

\begin{itemize}[leftmargin=2em]
\item The principal, diagonal, and cross-cell gates
  \eqref{eq:correct-principal-gate}--\eqref{eq:correct-cross-gate}
  are not proved.
\item Fine-cell injectivity is vacuous, not branchwise or global
  multiplier dispersion.  Different \(z\)'s of the same \(\beta\)
  are forced multiplier collisions.
\item The positive carrier is not identified with the original
  signed \(z\)-fiber sum.
\item No complete short- or generic-sector bound, affine M\"obius
  cancellation theorem, determinant-energy lower bound, TPC-18
  cover, parity breakthrough, Hardy--Littlewood asymptotic,
  prime-pair lower bound, or twin-prime conclusion is proved.
\item Nothing is specialized to \(h_0=2\).
\end{itemize}

The audit weakens the interpretation of cellwise injectivity but
makes the literal crosswalk correct.  The paper removes one opened
submass and exposes the true remaining collision gate; it does not
claim \(\Ltwo\) progress.
