# Roadmap after RH-322

RH-322 certifies the exact local row at critical clearance.  The physical
folded row converges to a half-line Gaussian indexed by
`d = delta/sigma`, with an exact total-variation tail.  The index is genuine:
different subsequential clearance phases give different profiles.

RH-323 should build the paired affine Gaussian chain for the endpoint and the
first repelling-boundary contact of the same time-ordered orbit.  It must:

1. retain the common clearance phase rather than assume a universal `d`;
2. preserve the two orientations and exact row normalizers;
3. state an operator or kernel conclusion for the pair, not a full trace law;
4. leave parity, neighboring-shell cancellation, curvature, and the
   moving-order Duhamel remainder explicit for RH-324--RH-328.

No joint first-alias reopening theorem has yet been supplied.  Gates A--E
remain false/open.
