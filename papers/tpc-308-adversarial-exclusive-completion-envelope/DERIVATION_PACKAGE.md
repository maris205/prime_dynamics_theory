# TPC-308 derivation package

## Frozen parent object

For each adjacent pair of shells in TPC-307, let

```text
U = S_left union S_right,
O = S_left intersect S_right,
E_left = S_left \ O,
E_right = S_right \ O.
```

TPC-307 fixes the common physical matrix `V_U`, the overlap-only coefficient
vectors `c_left,c_right`, the common comparison prefix `k`, and the aligned
native exclusive targets `h_left,h_right`.  TPC-308 does not refit any of
these objects.

## Completion envelope

For a binary target `h in {-1,+1}^m` and radius `r`, define

```text
C_r(h) = { h' : h'_j in {-1,+1}, d_H(h',h) <= r }.
```

For a fixed prediction `y in R^m`, the directional envelope is

```text
L_r^-(y,h) = min_{h' in C_r(h)} m^(-1) ||y-h'||_2^2,
L_r^+(y,h) = max_{h' in C_r(h)} m^(-1) ||y-h'||_2^2.
```

The producer enumerates subsets of coordinates to flip.  Consequently

```text
|C_r(h)| = sum_{j=0}^{min(r,m)} binom(m,j).
```

For a pair of directional predictions, the conservative ratio enclosure is

```text
[ L_r^-(y_R,h_R) / L_r^+(y_L,h_L),
  L_r^+(y_R,h_R) / L_r^-(y_L,h_L) ],
```

with the producer's stated numerical padding.  A ratio interval wholly below
`0.9` is right-lower; one wholly above `1.1` is left-lower; otherwise it is
unresolved.

## Exact finite facts

1. The completion set is a finite union indexed by flip subsets.
2. Exhaustive enumeration attains both extrema for a fixed prediction.
3. `C_r(h) subset C_{r+1}(h)`, hence the lower envelope is nonincreasing and
   the upper envelope is nondecreasing.
4. `C_0(h)={h}`, so radius zero recovers the native TPC-307 holdout loss.
5. Simultaneously changing `y,h` to `-y,-h` preserves every completion loss.

These are finite statements.  They do not say that a completion selected from
the envelope is generated by the arithmetic source, nor that the envelope
has an asymptotic interpretation.

## Observed finite atlas

The locked replay has 18 cases.  At radii `0,1,2`, the agreement counts are

```text
r=0: 13 concordant, 3 discordant, 2 unresolved
r=1: 11 concordant, 2 discordant, 5 unresolved
r=2: 10 concordant, 1 discordant, 7 unresolved.
```

The discordance counts by transition are `(0,0,3)`, `(0,0,2)`, and
`(0,0,1)` for `50->60`, `60->70`, and `70->90`, respectively.  Thus the
obstruction attenuates but does not vanish by radius two.  The growing
envelope also widens several ratios across the undecided band; this is a
finite sensitivity statement, not evidence of a preferred completion.
