# RH-214: monotone axial shape clock

Across sixteen predeclared scales, the axial coordinate `u` increases strictly
on both channels through all fifteen transitions.  For `sigma <= 0.02`, the
asymmetry coordinate occupies corridors of width `0.03557` (left) and
`0.03717` (right); mature channel discrepancies stay below `0.00301` in `u`
and `0.00305` in `eta`.  These are finite facts and define a piecewise-linear
clock only on the sampled interval.
