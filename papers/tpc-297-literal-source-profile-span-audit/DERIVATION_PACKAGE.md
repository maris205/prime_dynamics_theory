# TPC-297 derivation package

## 1. Literal profile family

For an integer `t`, let `lambda(t)` be `1/k` when `t` is a power of a prime
with exponent `k`, and zero otherwise.  For a finite local cutoff `z`, set

```text
beta_z(t) = lambda(t) - sum_{d<=z, d|t} mu(d).
```

On the frozen source interval `I`, put
`U=[beta_3 beta_5 beta_7 beta_11]`.  The physical columns `A` are the
TPC-295 columns generated by the registered frozen source.  The restricted
source-correlation image is

```text
V = A^T U.
```

This is a source-side span: no target-dependent direction is selected.

## 2. Projection theorem

For any real matrix `V` and target `b`, let `P_V` be the orthogonal
projection onto `col(V)`.  Then

```text
min_c ||Vc-b||_2^2 = ||(I-P_V)b||_2^2 = b^T(I-P_V)b.
```

If `V` has full column rank, `P_V=V(V^T V)^(-1)V^T`; otherwise use the
Moore--Penrose inverse.  The proof is the decomposition
`b=P_V b+(I-P_V)b` with orthogonal summands.

## 3. Nested profile spaces

If `U_1` is obtained by deleting columns from `U_2`, then
`col(A^T U_1) subseteq col(A^T U_2)`.  Therefore the best residual cannot
increase when a literal source profile is added.  Since `beta_5` or
`beta_7` is the registered frozen beta on every row, the four-profile
residual is no larger than TPC-296's one-ray residual.

## 4. Finite rank and numerical protocol

All source profiles and physical entries are rational on a finite row.
Gaussian elimination modulo `1000000007` and `998244353` certifies the rank
of `V`; the producer then converts exact entries to 70-digit arithmetic and
uses QR least squares.  The independent checker accumulates each physical
column source-first and repeats the projection calculation without importing
the producer.

The finite statements do not imply a lower bound on the rank as `N` grows,
nor a principal-angle theorem for the full arithmetic source class.
