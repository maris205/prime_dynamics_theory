# RH-379 updated roadmap

RH-379 closes the exact all-finite-clock supremum for universally safe
phasewise lag-two tables with `c11(r)=0` at every phase.  It also proves
exact square-clock memory gains and their vanishing correction to the
RH-374/RH-375 endpoint.

The first unresolved object is a natural-average theorem for the
phase-weighted shift-two sums

```text
sum_(n<=N) w_(n mod q) mu(n-2)mu(n).
```

Without that input, no successor may extend the result to phasewise
`c11(r)!=0` tables.  The admissible next routes are:

1. prove the required fixed-period phase-weighted shift-two cancellation, or
   a theorem that genuinely implies it;
2. resolve the RH-371/RH-377 adaptive two-envelope limit using new
   higher-order arithmetic input;
3. study a broader memory class only after its full mixed-moment interface
   is enumerated and each nonzero term is matched to a proved theorem;
4. retain geometrically selected measures and deterministic strong-space
   Ulam routes at their named `STOP_SCOPED` hypotheses.

The present proof authorizes no same-support memory-saturation theorem,
`Delta_y` monotonicity, finite-clock attainment/nonattainment conclusion, or
growing-clock exchange.  No current route supplies an intrinsic operator,
von-Mangoldt prime-power trace, completed-zeta divisor equality,
Riemann-zero identification, Hilbert--Polya construction, or RH proof.
