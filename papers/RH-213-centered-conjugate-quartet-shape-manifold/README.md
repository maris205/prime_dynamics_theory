# RH-213: centered conjugate-quartet shape manifold

A centered, RMS-normalized quartet consisting of two conjugate pairs is
parameterized exactly by `(u, eta) in [0,1] x [-1,1]`.  Its coefficients obey
`c3^2 = 4(2-c2)(1-c4)`, and the forward and inverse formulas reconstruct all
32 frozen physical endpoints to roundoff.  This is an exact quotient theorem,
not a fitted asymptotic law.
