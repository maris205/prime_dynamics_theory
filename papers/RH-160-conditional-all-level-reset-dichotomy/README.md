# RH-160: Conditional All-Level Reset Dichotomy

RH-160 states the first explicit all-level conditional theorem for the two
surviving reset routes.  Eventual overlap conditioning, a subunit selected
eigenvalue/tail ratio, and a positive selected recent/full spread imply a
uniform native support floor.  Adding a bounded-lag positive normalized
fourth-cross interface implies a uniform directional seed.

The interface sets are inclusion-minimal for these formulas, with five
explicit omission witnesses.  Every clause passes on the frozen atlas, but
the conservative finite floors range from `3.0883e-12` (native) to
`6.0283e-48` (directional using only worst consecutive overlap).  This is a
falsifiable conditional roadmap, not proof that the interfaces hold
eventually.
