## Seven AI-research failure modes

| Mode | Status | Repository-locked evidence |
|---|---|---|
| 1. Implementation bug passing self-review | CLEAR | Independent pointwise and cumulative identities, RH-371 endpoint alignment, and frozen rows agree |
| 2. Hallucinated citation | CLEAR (repository-locked) | Only frozen Davenport, Mirsky, Teräväinen--Walker, and repository metadata are used |
| 3. Hallucinated experimental result | CLEAR | Every stored integer is exactly regenerated; no fit or empirical inference is made |
| 4. Shortcut reliance | CLEAR | The proof takes `N->infinity` at fixed cutoff before cutoff removal; finite rows are not theorem evidence |
| 5. Bug reframed as insight | CLEAR | The symbolic identity and source theorem precede the computation |
| 6. Methodology fabrication | CLEAR | The described endpoint, loops, source locks, schema, and archive match executable files |
| 7. Early frame-lock | CLEAR | The result is stated as a hardness equivalence and leaves higher runs and alternate routes open |
