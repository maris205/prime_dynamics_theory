# TPC-364 computational protocol

The panel and beta menu are fixed before the complete certificate is rebuilt.
No source vector, response value, or adaptive sign law is read.  The producer
accumulates prime blocks in increasing shell order.  The independent checker
uses the same literal formula but traverses each shell in reverse order.

For each row it records raw and weighted-geometry-normalized Schur norm,
Frobenius norm, extreme spectrum, weight range, and effective shell count.
There are `3*2*4*2*4*5=960` rows.  The rational anchor uses `Q=4`, shell
`{5,7}`, exponent 1, and interval `[313060,313073]`.

The stress protocol applies 18 mutations and requires every one to be
rejected without changing the baseline certificate.  The Bridge-B checker
locks all claim-bearing files, checks the PDF/compile log, and runs producer,
independent checker, and stress in both normal and optimized modes.
