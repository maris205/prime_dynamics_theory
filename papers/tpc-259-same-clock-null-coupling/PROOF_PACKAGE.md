# TPC-259 proof package

## Theorem (same-clock null-channel suppression)

Retain the literal V59 object, operator, and four-block source frame of
TPC-258, and let `z=z_null`.  For every fixed admissible hybrid parameter `K`
and every fixed `M>0`,

```text
|<z,w>| <<_(M,K) x^(1/2)/(log x)^M.
```

Together with the TPC-258 theorem
`<z,A_x beta>=o(x^(7/6)/log^3 x)`, this implies

```text
conjugate(<z,w>)<z,A_x beta>
 =o(x^(5/3)/log^(M+3) x).
```

The conclusion is a source-backed estimate for one explicitly identified
rank-one channel of the signed scalar, not for the full scalar.

## Proof

Let `B_1,...,B_4` be the consecutive blocks and write `W_j=sum_(n in B_j)w(n)`.
TPC-254's maximal Type-I extraction applies to every active consecutive
interval, so for fixed `M,K`,

```text
|W_j| <<_(M,K) x/(log x)^M.
```

The block sizes satisfy `s_j=x/8+O(1)`, and the adjacent Haar factors satisfy
`rho_j=sqrt(x)/4+O(x^(-1/2))`.  Hence

```text
|<z1,w>| <=rho_1(|W_1|/s_1+|W_2|/s_2)
             <<sqrt(x)/(log x)^M,
```

and the same estimate holds for `z2`.  The fixed coefficients `L2/LT` and
`-L1/LT` then give the displayed bound for `<z,w>`.

Now put `S_x=x^(7/6)/log^3 x`.  TPC-258 gives
`<z,A_x beta>=S_x e(x)` with `e(x)->0`.  Therefore

```text
|conjugate(<z,w>)<z,A_x beta>|
 <=C_(M,K) sqrt(x)/(log x)^M * S_x |e(x)|
 =o(x^(5/3)/log^(M+3) x).
```

## Exact residual identity

With `c=<z,w>`, define `w_parallel=c z` and `w_perp=w-cz`.  Since `z` and
`w` are real, `c` is real; retaining conjugation makes the Hilbert identity
valid without a reality assumption on the output:

```text
<w,A_x beta>=conjugate(c)<z,A_x beta>+<w_perp,A_x beta>.
```

This follows by linearity in the second slot and conjugate-linearity in the
first.  The residual is orthogonal to `z`, but no estimate for it is supplied.

## Synthetic obstruction

In `R^2`, take `z=(1,0)`, `w=(0,1)`, `beta=(1,0)`, and
`A=[[0,0],[lambda,0]]`.  The diagonal is zero and `A beta=(0,lambda)`.  Thus
`<z,w>=0`, the null channel vanishes, while
`<w,A beta>=lambda`.  This proves only a structural non-promotion statement;
it is not asserted to be generated by the literal prime shell.

## Conditional refinement

If the two scalar remainders in TPC-258 have the conditional
`O(S_x/log x+x^(55/48+epsilon))` rate, multiplication by the four-block `w`
bound gives

```text
|null_channel|
 <<_(M,K,epsilon) x^(5/3)/log^(M+4) x
                 +x^(79/48+epsilon)/log^M x.
```

This remains a `CONDITIONAL_THEOREM`; it is not a fixed-power global estimate.
