# TPC-280 computational protocol

All certificate arithmetic uses Python `Fraction` and canonical JSON.  The
producer locks the released TPC-279 producer and result hashes.  Six exact
two-term cases, four margin cases, four endpoint cases, and all twelve parent
rows are regenerated from source data.  The independent checker reconstructs
the formulas without importing the producer.  The stress audit mutates theorem,
budget, endpoint, transfer, and parent-binding fields; every mutation must be
rejected in both normal and optimized modes.
