# TPC-272 computational protocol

1. Read the committed TPC-271 JSON as the frozen parent certificate and verify
   its payload SHA-256.
2. Form each positive interval `m^6=Xi_C/Xi` by outward rational division.
3. Form four dyadic sixth-power ratios and compare them with exact rational
   thresholds `(1/32)^6` and `4^6`.
4. Run the producer, independent replay, and hostile stress audit with both
   normal and optimized Python.  Their stdout must match within each pair and
   stderr must be empty.
5. Build both copies of the PDF, inspect the complete LaTeX log, text,
   embedded fonts, and every rendered page.

The finite rows are inherited diagnostics, not an asymptotic sample.  No
randomness, Monte Carlo estimate, or unregistered cutoff is used.
