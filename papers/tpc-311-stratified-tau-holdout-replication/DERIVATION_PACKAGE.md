# TPC-311 derivation package

## 1. Parent observation

For a fixed profile ladder `j`, transition `q`, exponent `e`, tolerance `tau`,
and radius `r`, the TPC-309 certificate supplies positive extrema

```text
R_{j,q,e,tau,r}^- <= R_{j,q,e,tau,r}^+
L_{j,q,e,tau,r}^- <= L_{j,q,e,tau,r}^+.
```

The superscript `-` on `R` and `L` denotes the lower endpoint of the
corresponding minimum envelope; the `+` denotes the upper endpoint of the
maximum envelope used by the conservative ratio enclosure.

## 2. Within-stratum profile pooling

For the design stratum `s=(q,e,tau,r)`, define

```text
P_s = [ sum_j R_{j,s}^- / sum_j L_{j,s}^+,
        sum_j R_{j,s}^+ / sum_j L_{j,s}^- ],
```

where `j` runs over LOW, BASE, and HIGH.  The profile ladders are replicated
within a fixed design cell; no ladder is allowed to receive a loss-scale
weight at this stage.

## 3. Between-stratum design-equal map

For a nonempty block `B` of design strata, define

```text
S(B) = [ |B|^{-1} sum_{s in B} P_s^-,
         |B|^{-1} sum_{s in B} P_s^+ ].
```

The primary blocks are native radius zero with calibration taus, confirmation
tau, and the full tau grid.  The all-radius blocks repeat the same calculation
with `r=0,1,2`.

## 4. Holdout relation

Let `C` be the calibration block and `H` the confirmation block.  Define

```text
REPLICATED       if C and H have the same strict class;
REVERSED        if one is strict RIGHT and the other strict LEFT;
UNRESOLVED      otherwise.
```

The strict class rule is `RIGHT` when the upper endpoint is below `0.9`,
`LEFT` when the lower endpoint exceeds `1.1`, and `UNRESOLVED` otherwise.

## 5. Design census

The complete factorial design has

```text
3 transitions x 2 exponents x 3 taus x 3 radii = 54 strata,
54 strata x 3 profile ladders = 162 parent observations.
```

The calibration/confirmation tau sets are disjoint and cover the declared
three-point tau grid.  This is a finite partition identity, not a claim of
statistical independence.

## 6. Numerical boundary

All displayed maps are exact finite monotone operations on the decimal
interval endpoints locked by TPC-309.  The physical parent values were
generated by a float replay with padded enclosures.  Consequently the atlas
is `NUMERICALLY_REPRODUCED_FINITE`, not a directed-rounding theorem and not
an asymptotic statement.
