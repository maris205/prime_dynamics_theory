# RH-275: Archived cloud Fourier-defect audit

The seven RH-15 clouds are re-audited against the exact Hardy-scaled
monodromy shell using aggregate root, phase, radial, and moment defects.
Across the frozen rows, the total matching error is `0.6424–1.2481` and
`N` times the mean root error is `0.3212–0.6240`.  The largest pre-alias
moment defect is `0.5096–1.4573`.

These are floating diagnostics of archived Arnoldi roots.  Seven finite rows
cannot prove convergence or nonconvergence of the actual noisy cloud.
