# RH-218: autonomous shape-recurrence obstruction

On the dyadic subsequence, a two-dimensional affine map fits three training
transitions almost exactly but misses the two holdout transitions by as much
as `0.0426--0.0506`; the pooled maximum is `0.04685`.  Conversely, every
finite orbit with distinct `u` coordinates admits an exact autonomous
polynomial interpolant.  Therefore finite recurrence existence is
non-identifying, while the tested low-complexity semigroup is not predictive.
