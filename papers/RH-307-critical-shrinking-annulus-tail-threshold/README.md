# RH-307: Critical shrinking-annulus tail threshold

At the minimal clock and radius `rho_sigma = R exp(eta_sigma)`, the certified
noisy-tail scale is

    exp(a_star L_sigma eta_sigma) / L_sigma.

For `eta_sigma = c log(L_sigma)/L_sigma`, the sharp mass-and-cap information
class threshold is `c = log(10/7)`.  A repeated-`q` diagonal model saturates
the subcritical, critical, and supercritical orders.  The moving head is not
controlled.

The reported `sigma=1e-80` radii all lie below `rho_star`.  Gates A--E remain
open.
