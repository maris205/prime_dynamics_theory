# RH-313: Parity-orthogonal endpoint Hardy splitting

The universal endpoint logarithm splits into orthogonal Hardy channels

    L_even(w) = (1/2) log(1-w^2),
    L_odd(w)  = w + (1/2) log((1-w)/(1+w)).

The analytic remainder from RH-312 splits in the same way.  Therefore
endpoint `H2` convergence is equivalent to simultaneous convergence of the
even and odd projections, with exact Pythagorean norm identity.

This is a structural criterion.  Neither projected noisy convergence nor the
full endpoint theorem is claimed.  Gates A--E remain false/open.
