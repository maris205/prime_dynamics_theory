# TPC-410 derivation package

The complete-shell local identity is unchanged when the height changes: only
the window `N=4H` and the kernel sums `S_0,S_1` change. Since the fixed
`Q=131072` shell is odd, the exact profile has 5374 odd-index and 5375
even-index primes. The Cauchy--Schwarz step uses the actual odd count
`P_-^2<=m_-V_-`; the factor cancels against `V_->=m_-a_min^2`. Thus the
same finite `4/H` bound applies to every height in the declared ladder.
