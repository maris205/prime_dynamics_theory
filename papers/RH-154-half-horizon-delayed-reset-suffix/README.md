# RH-154: Half-Horizon Delayed Reset Suffix

RH-154 proves finite-prefix invariance for the reset support problem and an
exact retention-versus-conditioning theorem for terminal suffixes.

Keeping the terminal half of every frozen reset chain retains 62 of 120
transitions while raising the common robust overlap from `8.9866e-5` to
`0.0666397`.  The worst inverse bound falls from `11127.6` to `15.0061`, and
the maximum log drawdown falls from `32.0150` to `8.9730`.  The minimum
correlated transported base remains positive at `2.2304e-7`.
