# RH-274: Fourier-defect criterion for a cloud bridge

Rootwise phase convergence is not enough for a rank-growing cloud.  The
relevant quantities are the low-frequency aggregate Fourier defects.  The
paper gives a sufficient `l1` phase/radius criterion and an exact common-shift
counterexample: a shift `delta_N=(N+1)^(-1/2)` tends to zero pointwise, while
the third cloud moment grows like `-4 beta^3 sqrt(N+1)/pi`.

This is a logical obstruction to promoting the RH-15 phase fit; it does not
show that the archived noisy cloud follows the counterexample.
