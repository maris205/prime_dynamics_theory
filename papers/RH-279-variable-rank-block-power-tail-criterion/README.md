# RH-279: Variable-rank block-power tail criterion

We formulate the direct replacement for the failed fixed-space RH-269 route.
The Hilbert spaces and selected ranks may vary with noise.  If a growing
block length `m_sigma` has tracked trace-norm and operator-norm power bounds,
then the RH-246 logarithmic tail estimate holds beyond that moving head; the
paper states the additional root-rate condition that makes this bound vanish.

This theorem is conditional: the required variable-rank block certificates
are not archived.  It is an executable target rather than a claim of closure.
