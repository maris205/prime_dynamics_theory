## Abstract

TPC-295 proved that the unrestricted finite source-correlation map attached to a physical prime shell is onto, but existence alone does not measure its cost. This paper derives the exact least-norm source budget for a target and an exact source-cost/physical-energy tradeoff. If $A$ contains the physical shell vectors and $G=A^{\mathsf T}A$, then the minimum source norm for $A^{\mathsf T}h=b$ is $b^{\mathsf T}G^{-1}b$, attained by $h=AG^{-1}b$. On the inherited 18-row literal grid, a 70-digit replay finds that all 18 TPC-294 weighted minimizers have cost below $10^{-3}\left\lVert \beta\right\rVert^2$ in the unrestricted source space. In contrast, even the enlarged one-dimensional proxy generated by the frozen source vector has normalized least-squares residual at least $0.9$ on all 18 weighted targets. The finite evidence therefore moves the obstruction from raw unrestricted source energy to the dimension and geometry of the native profile. No growing, arithmetic $L^2$, or twin-prime conclusion follows.

# Position on the route

This release remains in the same literal prime-shell dynamical family. TPC-293 compiled pairwise sign preferences into a whole-shell signed graph, and TPC-294 restored the physical Gram magnitudes and found a global weighted sign optimizer on each inherited row `\cite{tpc293,tpc294}`. TPC-295 then proved that these ambient targets have finite rational source preimages whenever the shell Gram matrix is nonsingular `\cite{tpc295}`.

The remaining question is quantitative: is the preimage affordable, and is it aligned with the source family that generated the physical vectors? The first part has an exact answer. The second is tested here only through a declared one-dimensional proxy, so that a finite obstruction is not mistaken for a theorem about all native profiles.

# Physical shell and source correlation

Let $I=I_N$ be the frozen integer interval. For an odd prime $q$, height $H$, and exponent $s$, write $$K_{H,s}(v)=\frac{H^{2s}}{(H^2+v^2)^s},\qquad
 B_q(u,t)=\mathbf 1_{q\nmid u}\mathbf 1_{q\nmid t}
 \left(\mathbf 1_{u\equiv t\pmod q}-\frac1{q-1}\right).$$ The deleted-diagonal physical component inherited from the frozen source vector $\beta$ is $$(g_q)_u=\sum_{t\in I,\ t\ne u}
 qK_{H,s}(u-t)B_q(u,t)\,\beta_t,\qquad u\in I.
 \label{eq:physical}$$ For $S=\{q:Q<q\le 2Q\}$, put $$A=[g_q]_{q\in S}\in\mathbb{Q}^{I\times S},\qquad G=A^{\mathsf T}A,qquad
 C=A^{\mathsf T}:\mathbb{Q}^I\to\mathbb{Q}^S.
 \label{eq:matrix}$$ For a target $b\in\mathbb{Q}^S$, its unrestricted source cost is $$S_A(b)=\min\{\left\lVert h\right\rVert_2^2:A^{\mathsf T}h=b\}.
 \label{eq:cost}$$ The finite source domain in this paper is the full rational coordinate space; the original arithmetic profile is not silently identified with it.

# Exact source-budget theorem

> **Theorem: Least-norm source budget** Suppose $A\in\mathbb{R}^{n\times m}$ has full column rank and $G=A^{\mathsf T}A$. For every $b\in\mathbb{R}^m$, the constraint $A^{\mathsf T}h=b$ is feasible and $$S_A(b)=b^{\mathsf T}G^{-1}b,
>  \qquad h_b=AG^{-1}b
>  \label{eq:leastnorm}$$ is its unique minimum-norm solution. Consequently, for any $B\ge0$, there is a solution with $\left\lVert h\right\rVert_2^2\le B$ if and only if $b^{\mathsf T}G^{-1}b\le B$.

> **Proof** The vector $h_b=AG^{-1}b$ satisfies $A^{\mathsf T}h_b=GG^{-1}b=b$. Every other solution is $h_b+v$ with $v\in\ker(A^{\mathsf T})$. Since $h_b\in\operatorname{col}(A)$ and $\operatorname{col}(A)=\ker(A^{\mathsf T})^\perp$, Pythagoras gives $$\left\lVert h_b+v\right\rVert_2^2=\left\lVert h_b\right\rVert_2^2+\left\lVert v\right\rVert_2^2.$$ Finally, $\left\lVert h_b\right\rVert_2^2=b^{\mathsf T}G^{-1}A^{\mathsf T}AG^{-1}b
> =b^{\mathsf T}G^{-1}b$. The budget statement follows from minimality.

> **Proposition: Source-cost/physical-energy tradeoff** Under the hypotheses of the theorem, define $$E_A(b)=\left\lVert Ab\right\rVert_2^2=b^{\mathsf T}Gb.$$ Then $$S_A(b)E_A(b)\ge (b^{\mathsf T}b)^2.
>  \label{eq:tradeoff}$$ For a sign target in $\{-1,+1\}^m$, the right-hand side is $m^2$.

> **Proof** Apply Cauchy–Schwarz to $G^{1/2}b$ and $G^{-1/2}b$. Their inner product is $b^{\mathsf T}b$, while their squared norms are $E_A(b)$ and $S_A(b)$.

The inequality is a useful interface statement: physical cancellation and source affordability cannot both be made arbitrarily strong for the same target. It is exact linear algebra, not an arithmetic estimate.

# A declared native-ray diagnostic

Let $\beta$ be the frozen source vector and define its correlation vector $$v=A^{\mathsf T}\beta.$$ We enlarge the literal frozen direction to the ray proxy $\{\alpha v:\alpha\in\mathbb{R}\}$. This is intentionally generous: failure of the proxy does not say that a richer source family fails.

> **Proposition: Least-squares distance to the source ray** If $v\ne0$, then for any target $b$ $$\min_{\alpha\in\mathbb{R}}\left\lVert \alpha v-b\right\rVert_2^2
>  =\left\lVert b\right\rVert_2^2-\frac{(v^{\mathsf T}b)^2}{v^{\mathsf T}v}.
>  \label{eq:ray}$$ For a sign target, the square root after division by $\sqrt{m}$ is its normalized ray RMS residual.

> **Proof** Complete the square in $\alpha^2v^{\mathsf T}v-2\alpha v^{\mathsf T}b+b^{\mathsf T}b$.

# Finite protocol

The audit inherits eight $s=2$ growth rows, four $s=1$ exponent-crossover rows, and six $s=2$ source-control rows from TPC-295. On each row, the physical columns are first accumulated exactly as rational numbers. The producer then converts them to 70-digit arithmetic, diagonalizes $G$, and solves for the TPC-294 weighted minimizer, the unit-edge max-cut target, and the all-positive target. It records conservative decimal enclosures for cost, energy, condition number, trade product, and ray residual.

The independent replay changes the accumulation order: it builds each column source-first and does not import the producer. It checks the source correlation residual and the identity $\left\lVert AG^{-1}b\right\rVert_2^2=b^{\mathsf T}G^{-1}b$. Exact rational fixtures attack both full-rank and duplicated-column singular cases.

The declared diagnostics are $$\tau(b)=\frac{S_A(b)}{\left\lVert \beta\right\rVert_2^2},qquad
 \tau(b)<10^{-3},qquad r_{\rm ray}(b)\ge0.9.
 \label{eq:diagnostics}$$ They are finite modeling choices and carry no exponent credit.

# Interpretation and route boundary

TPC-295’s broad image question is therefore not obstructed by a large unrestricted least-norm witness on this finite grid. This is a useful positive result: one cannot reject the weighted sign direction merely on the basis of ambient source energy. The same data reveal a different obstruction. The weighted minimizer is nearly orthogonal, in correlation space, to the frozen-beta ray on every row. A one-dimensional native proxy is consequently too small or points in the wrong direction for these targets.

The conclusion is deliberately limited. The actual Mobius/comparison source class may have several independent directions, and the present calculation does not determine its dimension or image. The source-control cutoff triples also coincide in this physical construction because the frozen $\beta$ used for the columns is unchanged; this is a modeling boundary, not cutoff-uniform arithmetic evidence. Finally, a finite condition-number range is not a growing-shell bound.

The claim ceiling is thus $$\texttt{PROVED\_EXACT\_FINITE}\quad+\quad
\texttt{NUMERICALLY\_CERTIFIED\_FINITE}\quad+\quad
\texttt{NUMERICAL\_OBSERVATION},$$ with fixed-power credit zero. Literal arithmetic $L^2$, a restricted profile theorem, Gate B, and the twin-prime endpoint remain open.
