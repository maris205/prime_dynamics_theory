# RH-382 updated roadmap

RH-382 closes the two-scale second-order trigger opened by RH-381. The exact
chain is

```text
RH-381 infinite increment sum
  -> Bonferroni and inverse-product inequalities
  -> X_j = X_infinity + Y_infinity T_j + O(T_j^2), explicit 931/4
  -> M_j/A_j = m_infinity + O(T_j), explicit 63
  -> quadratic H loss
  -> exact T_y^2+S_y and T_y^2-S_y identities
  -> cube telescopes
  -> 931/2 + 254/3 = 3301/6 < 551
  -> uniform two-scale theorem for every y>=1.
```

The proof retains the terminal `R8=P_yE8`, uses `E9=0` exactly, and does
not invent `E10`. Computing more finite tails or fitting a decay curve does
not strengthen this theorem.

## Scoped within-class successor

The exact RH-379 identity `G(q_y)=B_y+Delta_y` suggests rewriting the gap as
a finite combination of `U_m=u_m/product_tail(1-(m-1)a)` and
`H=(4/pi^2)product_tail(1-a)`, then seeking an exact cluster/exponential
normal form in the power sums `P_r=sum a^r`. This is only a candidate for an
arbitrary-order coefficient algorithm; RH-382 proves second order with a
cubic remainder and does not claim that all-order theorem.

## Class-enlargement blockers

The first route beyond phasewise `c11=0` still requires a natural-average
theorem for every fixed-period weighted shift-two Mobius correlation that
appears in the interpolation. No locked source supplies it.

Other genuine reopen triggers remain:

1. a fixed non-Parry equilibrium state with the required mixing theorem,
   rather than an externally selected measure;
2. a deterministic fractional/tower-adapted strong-space Ulam theorem with
   a mesh-independent norm, uniform lift/projection estimate, and common
   contour around `-1`;
3. a composite-order primitive-divisor theorem, sharp return-radius law,
   finite-entropy-data theorem, or intrinsic globalization theorem that
   actually supplies its stated missing bridge;
4. one of the original same-clock physical Gates A--E.

There is no `p_y` rewrite, growing clock `q(N)`, adaptive-capacity limit,
intrinsic spectral determinant, prime-power trace formula, Riemann-zero
identification, Hilbert--Polya construction, or RH implication. Gates A--E
remain false/open.
