2. Rebuild each physical shell from the source-first finite engine.
3. Form the exact rational image V=A^T U and source Gram M=U^T U.
4. Read the frozen TPC-299 ridge interval and select its 20-significant-digit
   rational midpoint rho.
5. Solve (V^T V+rho M)c=V^T b by Fraction Gauss-Jordan elimination.
6. Compute the exact rational dual value
   (||b||^2-R^2-b^T Vc)/rho.
7. Store decimal enclosures plus hashes of the exact fraction and coefficient
   vector.
8. Replay all cases in a producer-independent checker and run the scalar and
   matrix stress fixtures in normal and optimized Python modes.
