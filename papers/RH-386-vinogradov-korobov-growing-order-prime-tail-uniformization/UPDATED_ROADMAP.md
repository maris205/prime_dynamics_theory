# RH-386 updated roadmap

## Route A: GO

RH-386 closes the growing-order prime-tail step under the explicit
Johnston--Yang Vinogradov--Korobov envelope:

```text
strict prime tail
  -> exact Stieltjes boundary
  -> decreasing hazard and source transfer
  -> exact-to-power kernel comparison
  -> Laplace leading-kernel comparison
  -> growing partition ledger
  -> sharp H/L obstruction.
```

The output can be reused whenever a later theorem has already reduced its
arithmetic remainder to products of the strict tails `P_r(y)` and can
verify the two independent budgets

```text
d epsilon_x + d/x^2 -> 0,
H/L -> 0.
```

The first pays for source and power-kernel uniformity. The second is the
separate leading-kernel criterion and cannot be inferred from degree alone.

## Route B: STOP_SCOPED

Stop rather than extrapolate if a proposed consumer requires any of:

- a clock varying with the prefix length;
- active phasewise `c11` cancellation;
- a partition family violating `7R epsilon_x<=1/2` without a stronger
  prime-counting input;
- removal of `H/L` from the leading condition;
- an effective first index rather than an asymptotic statement;
- an operator, trace, zero-divisor, or RH conclusion.
