# RH-317: Sharp spectral-prefix rank and mass law

Let `s=q_star/q=1.4017504517095518...`.  Among all finite spectra in
`|mu|<=q` that match the deterministic moments through order `N`, both the
least rank and the least squared spectral mass obey

    Theta(s^N).

The lower bounds come from the `N`-th power sum.  The upper bounds use the
divisor sparsity of the RH-315 packets together with the all-order envelope
`|a_n|<=C q_star^n`: an earlier order `e` can affect order `d` only when
`e` divides `d`.

This is a sharp theorem for synthetic finite spectral realizations.  It is
not a rank or mass theorem for the actual noisy spectrum.  Gates A--E remain
false/open.
