# Computational protocol

The producer regenerates every prime in every complete shell with an integer
sieve. It computes shell amplitudes, parity ledgers, row energies, diagonals,
and bounds using `fractions.Fraction`; no decimal is used in the theorem
path. Canonical JSON has sorted keys, compact separators, a terminal newline,
duplicate-key rejection, non-finite-constant rejection, and a SHA-256 digest.

The independent checker has its own shell census, amplitude, epsilon/sigma,
and row-energy implementation and compares exact replay objects. The stress
checker mutates theorem signs, sigma fields, counts, heights, digests, and
firewall values and checks fail-closed rejection. Normal and optimized Python
modes are required.
