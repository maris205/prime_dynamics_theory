# RH-273: Minimal rank and uniqueness of the pole counterloop

Among conjugate-symmetric finite counterloops whose odd moments vanish and
whose even moments match the pole sequence through order `2N`, rank at least
`2N` is necessary.  At equality the factor is uniquely
`Pi_N((beta z)^2)`, up to permutation of counterloop atoms.  This turns the exact RH-272
bridge into a sharp rank statement; it does not identify a noisy spectral
cloud.
