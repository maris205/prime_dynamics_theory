# RH-219: fixed-quartic counting obstruction

A bounded-degree locally uniform nonzero determinant family has bounded zero
count.  Repeating a quartic can make algebraic degree and multiplicity grow,
but its distinct zero support remains at most four; if those compact
multiplicities diverge, the divisor is not locally finite.  In the audit,
quartic powers reach degree 256 while retaining exactly four support points.
Gate A therefore requires genuinely new roots in a rank-growing family.
