# TPC-413 derivation package

If `o_s=r+sL` with `s=1,2,3`, then `o_s mod p_i=r mod p_i` for every pooled
prime.  The masks, energies, signs, and normalized values therefore agree
exactly across representatives.  Combining this CRT invariance with the
TPC-412 height argument gives the same sharp and coarse bounds in all 12 rows.
