# TPC-334 computational protocol

1. Verify the TPC-333 normalized parent hashes and certificate header.
2. Rebuild the six source arrays with the inherited finite cutoff and guards.
3. For every coordinate, classify `Lambda(t+2)b(t)` by the four declared
   support classes.
4. Sum counts, cross masses, fractions, and the partition residual.
5. Check the exact abstract support anchor and canonical JSON digest.
6. Replay with an independent trial sieve, reverse factorization, and reverse
   finite-tail product order.
7. Run five mutation tests and normal/optimized output equality.

The dense signed-Gram operator is intentionally absent: this project isolates
the arithmetic support of the source cross term.
