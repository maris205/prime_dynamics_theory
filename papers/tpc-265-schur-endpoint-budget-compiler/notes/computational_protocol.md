# TPC-265 computational protocol

The certificate uses exact rational arithmetic for centers, radii, maxima,
minima, and endpoint fractions.  The independent checker reconstructs the
radial envelope without importing the producer.  The stress checker enumerates
disk/circle cases, strict/borderline/loss budget lanes, and logarithmic-credit
firewall records.

The release checker freezes TPC-264 provenance, checks canonical JSON and the
complete project manifest, verifies both PDF copies, scans the LaTeX log,
checks embedded fonts and text, and compares normal/optimized child output.
