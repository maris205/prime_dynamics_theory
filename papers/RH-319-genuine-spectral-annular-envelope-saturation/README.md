# RH-319: Genuine spectral annular-envelope saturation

The exact-prefix spectra of RH-316 upgrade the RH-306 sharpness result from
an abstract coefficient family to genuine finite spectral power sums.  For
every fixed `R < rho < rho_star`, their `H-infinity(rho)` and `H2(rho)`
mismatch norms obey

    Theta_rho(M^(-kappa(rho))/log M),
    kappa(rho)=log(1/(q_star rho))/log(q_star/q).

The lower bound is the universal strict-annulus mass witness of RH-305; the upper bound uses
the exact spectral prefix and geometric spectral tail.  This proves sharpness
inside the finite normal spectral class.

It does not prove that the actual noisy complement realizes the sharp rate.
Gates A--E remain false/open.
