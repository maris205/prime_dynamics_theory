\section{Frozen source and setup}
\label{sec:source}

\subsection{Scales and common-source kernel}

We work with the frozen scales

\begin{equation}
 H=x^{21/32},\qquad Q=x^{1/3},\qquad U=x^{133/400},
 \qquad 4Q<H,\qquad U<Q.
 \label{eq:scales}
\end{equation}

Let

\[
 \Qx=\{q\text{ prime}:Q<q\leq2Q\},
 \qquad
 \Dx=\{d:H/(4Q)<d\leq U,\ \mu(d)^2=1\},
\]

and retain the literal source coefficient

\begin{equation}
 C_h=\sum_{\substack{d\in\Dx\\h\mid d}}\frac{\mu(d)\log d}{d}.
 \label{eq:Ch}
\end{equation}

For fixed packet profiles $\psi_j$, put
$M=\max_j\lVert\psi_j\rVert_\infty$ and define

\begin{align}
 B_{h,q}^{(j)}(a)
 &=\sum_{0<|m|\leq\lfloor hq/H\rfloor}
   \psi_j\!\left(\frac{Hm}{hq}\right)
   \one_{\{mq^{-1}\equiv a\ (\mathrm{mod}\ h)\}},
 \label{eq:B}\\
 K_j(n)
 &=\sum_{h\leq U}\ \sum_{\substack{a\ (\mathrm{mod}\ h)\\(a,h)=1}}
   C_h\left(\sum_{q\in\Qx}B_{h,q}^{(j)}(a)\right)
   \ee^{2\pi i n a/h}.
 \label{eq:K}
\end{align}

These formulas are not renormalized in this paper.  In particular, the
$q$-weight is one, the packet profiles are unchanged, $C_h$ is not replaced
by an absolute or averaged coefficient, and the frequency index remains
primitive.

\subsection{Inherited physical and analytic interfaces}

For a shell prime $q$, write

\begin{equation}
 S_{h,q}=\{mq^{-1}\pmod h:0<|m|\leq\lfloor hq/H\rfloor\}.
 \label{eq:physical-support}
\end{equation}

The row multiplicity is

\begin{equation}
 R_h(a)=\#\{q\in\Qx:a\in S_{h,q}\}.
 \label{eq:row-multiplicity}
\end{equation}

The inherited internal injectivity statement says that the multiplier map in
\eqref{eq:physical-support} is injective.  Indeed, if two allowed multipliers
have the same image, then

\[
 |m-m'|\leq2\lfloor hq/H\rfloor\leq4hQ/H<h,
\]

while $h\mid(m-m')$.  Hence $m=m'$.  This fact prevents hidden duplicates
inside one physical $q$-row.

The arithmetic input is the standard Brun--Titchmarsh estimate in a reduced
residue class,

\begin{equation}
 \pi(2Q;h,b)\leq
 \frac{4Q}{\ph(h)\log(2Q/h)},
 \qquad (b,h)=1,\qquad h<2Q,
 \label{eq:BT-standard}
\end{equation}

where $\pi(y;h,b)$ counts primes $p\leq y$ with
$p\equiv b\pmod h$; see, for example,
\citet{MontgomeryVaughan2007}.  The repository source lock locally verifies a
prior interval Brun--Titchmarsh use and this bibliography metadata.  It does
not contain a page-level scan of the cited book, so no page pinpoint is
claimed.

Finally, the inherited finite-window composition will be used only after the
new row estimate is proved.  Its direct coefficient-energy input is

\begin{equation}
 \sum_{h,a,j,q}|C_hB_{h,q}^{(j)}(a)|^2
 \ll JM^2\frac{Q^2}{H}(\log x)^5.
 \label{eq:direct-energy}
\end{equation}

All four ingredients---\eqref{eq:K}, physical injectivity,
\eqref{eq:direct-energy}, and the reduced-frequency large sieve---remain
unchanged.
