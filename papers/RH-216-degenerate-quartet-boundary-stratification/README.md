# RH-216: degenerate quartet boundary stratification

The shape discriminant factors exactly as
`256(1-u)^2(1-eta^2)[4u+(1-u)^2 eta^2]^2`.  This identifies every degeneracy
stratum and proves that `u -> 1`, uniformly in `eta`, forces the root multiset
toward the double pair `{+1,+1,-1,-1}` and the polynomial toward
`(z^2-1)^2`.  The finite data move in that direction but do not prove the
limit.
