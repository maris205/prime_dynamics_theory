# TPC-391 proof package

## Proved finite identities and checks

1. The selected affine intervals are pairwise disjoint from the declared prior
   panels and from one another.
2. The rational anchor has positive row geometry and symmetric law matrices.
3. The row census is exactly 448 and the cell census is exactly 32.
4. Every staged parent power for N >= 1280 is algebraically the same as its
   direct parent power; the recorded residual is finite arithmetic roundoff.
5. The independent checker reconstructs rows in descending prime-shell order
   without importing the producer.
6. The certificate is canonical JSON with a payload hash, fixed parent hash,
   fixed role metadata, and a 25-mutation rejection suite.

## What is not proved

The certificate does not prove a source-valid normalization, a growing
operator bound, origin or count uniformity, a uniform arithmetic L2 bound,
Route-A closure, Route-B reassembly, or any twin-prime theorem.  A finite
first crossing is only a scoped obstruction for the declared proxy panel.
