## 1. Frozen physical scalar

Retain the exact V59 data

```text
I_x=(x/2,x] intersect Z,
H=x^(21/32), Q=x^(1/3),
Q_x={q prime:Q<q<=2Q},
K_H(h)=hat(psi_+)(h/H),
u_1(a;q)=1_(a=1 mod q)-1/(q-1).
```

The physical coefficients `beta,w` are real.  On
`H_x=C^(I_x)`, with inner product conjugate-linear in the first slot, define

```text
A_x(u,t)
 = 1_(u!=t) sum_(q in Q_x)
     q 1_(q does not divide u)1_(q does not divide t)
     K_H(u-t)[1_(u=t mod q)-1/(q-1)].
```

The unit masks make `t^(-1) mod q` legal and identify the bracket with
`u_1(u t^(-1);q)`.  Hence the literal V59 Gate-B scalar is exactly

```text
C_x=<w,A_x beta>.
```

No transpose or adjoint is inserted: `u` is the output/`w` index and `t` is
the input/`beta` index.  If an unconjugated complex coefficient replaced the
real physical `w`, the first lane would have to be `conjugate(w)`.

## 2. Exactly-once hard source blocks

Fix any explicitly declared disjoint coordinate partition

```text
I_x = disjoint_union_(b in B) I_b
```

and let `P_b` be the corresponding orthogonal support projections.  Put

```text
beta_b=P_b beta,
w_c=P_c w,
A_cb=P_c A_x P_b.
```

Then

```text
A_x=sum_(b,c) A_cb,
C_x=sum_(b,c)<w_c,A_cb beta_b>.
```

Every admissible triple `(q,t,u)` has unique block labels `b=b(t)` and
`c=c(u)`, so its full summand---including the outer `q`, both unit masks,
the deleted diagonal and `K_H(u-t)`---occurs exactly once.  This is a hard
source-coordinate bookkeeping theorem.  V59's smooth bounded-overlap
partition remains a different exact weighted pair partition and is not
identified with these projections.

## 3. Tagged external two-lane covariance

For every ordered block pair introduce a tagged copy
`H_c^(b,c)` of `P_c H_x` and form

```text

B_ext = direct_sum_(b,c) A_cb beta_b,
W_ext = direct_sum_(b,c) w_c.
```

Orthogonality of the tags gives the exact literal source-index identity

```text

```

This resolves the existence of a finite physical-index two-lane covariance
representation.  It does **not** resolve the phasewise primitive-frequency

## 4. Exact norm obstruction

Let `m=|B|`.  Retaining all ordered block pairs forces

```text
||W_ext||^2 = m ||w||^2,
||B_ext||^2 = sum_(b,c)||A_cb beta_b||^2.
```

There is no general equality between the second quantity and `||A_x beta||^2`.
For singleton blocks on three coordinates, take

```text
A = [[0,1,-1],[0,0,0],[0,0,0]],
beta=(0,1,1).
```

Then `A beta=0`, while the two tagged block outputs are `+1` and `-1`, so
their squared direct-sum norm is `2`.  Thus the external attachment destroys
cross-input-block cancellation at norm level.  A direct TPC-243 error payment
using these copied lanes would therefore include a real duplication toll.
