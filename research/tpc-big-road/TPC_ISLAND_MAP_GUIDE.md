## 七座岛：研究对象，不是完成勾选

| 图中编号与名称 | 稳定含义 | 不可由图示推出的结论 |
|---|---|---|
| ① 基础算术岛 | 筛法、Möbius 相关、符号编码、素数分布结构及低维动力学类比的起点 | 出现“Möbius 相关”字样，不表示一般相关性问题已解决；动力学类比不等于算术识别定理 |
| ② 解析消去岛 | 局部输入的集体消去；大筛、移位卷积、Bessel–Gram 及相关算子路线 | 局部消去、有限算子界或无符号上界，不自动给出实际有符号全局节省 |
| ③ 固定原子岛 | 固定物理 `h0=2`、指定 packet、determinant-two 双 Möbius 原子及其归一化 | 锁定对象不等于获得该对象的逐点消去；冻结或周期情形不自动推广到完整物理权重 |
| ④ Pair-native / H1 结构岛 | 实际出现项载体、pair-to-ω 对应、opened-D packet 及对象合法化接口 | 上游行/cut 守恒、有限契约或选择器，不等于下游实际出现项的全覆盖、正确系数与归一化 |
| ⑤ 非自治动力学岛 | 保阶段编码、移动 gap-2 稀有事件、质量与协方差控制、指定算术初始点及动力学 Borel–Cantelli | 几乎处处或平均结果不等于对指定算术初始点成立；图中质量下界属于拟议路线条件，不是证明凭证 |
| ⑥ TPC 终点岛 | 孪生素数猜想：无穷多个孪生素数 | 编号增加、有限数值结果、局部定理或验证器通过，都不能据此宣布到达终点 |
| ⑦ Hénon / 几何提升岛 | 可选的几何视角、半共轭与保时提升等辅助路线 | 几何表示或提升本身不能代替算术消去、稀有事件控制或指定初始点典型性 |

图中的连接表达拟议输入、结构接口或替代路线，不意味着必须按编号依次走完，
也不是已证明的蕴含链。①提供起点，③和④涉及局部对象及合法载体，②承担解析消去；
⑤经动力学桥寻求通向⑥的另一条路线，⑦是辅助分支。只有来源明确的定理才能认证某段转移。

## 两座红桥与仓库 Gate 的名称对应

| 图上的名称 | 数学角色 | 与仓库名称的关系 |
|---|---|---|
| Bridge A，② → ⑥；核心算术估计 / four-Möbius collective saving | 在实际系数、符号、权重、掩码、参数范围和统一归一化下，实现通向终点的集体消去 | 仓库 Gate A（完整壳层有符号折叠）与 Gate B（集体二次型/四包素数 BDH 等表达）都在这座解析桥内部；它们的精确定义及替代路线以来源为准 |
| Bridge B，⑤ → ⑥；rare-event / distinguished-seed genericity | 将适用的动力学稀有事件机制落实到指定的算术初始点，并完成相应算术回接 | 对应仓库动力学/C 储备线；不是解析 Gate B |
| 文件或脚本名称中的 `Bridge-B` | 某个声明范围内的验证或发布流程标签 | 名称相同不构成数学对应；必须检查其真实验证范围，不能把 PASS 当作上述任一桥或 Gate 的闭合 |

## 怎样用图汇报与选路

对路线定位、进展回顾或候选路线，给出以下四项即可，不必把每篇论文都重新罗列：

1. **位置**：哪座岛、哪座图像桥；若涉及解析桥，再区分仓库 Gate A/Gate B。
2. **所得**：精确结构接口、限定条件下的实际算术结果、有限/模型证据，还是已证的物理转移；注明来源和适用范围。
3. **缺口**：距所需桥梁估计还差什么；沿用仓库对实际系数、固定 `h0`、前缀、参数范围、统一性、归一化和完整损失的要求。
4. **下一项**：只有在当前任务授权和 handoff 触发条件允许时才提出执行动作；否则报告精确边界，不凭地图启动研究。

例如：“这项工作位于②岛内、针对图像 Bridge A 的某个子问题；来源支持一个限定条件下的算子界，
尚需检验增长一致性及实际符号/权重的对应。”这种定位不预设该项工作已经支付桥梁所需的算术损失。

始终区分：双点局部结果与四点集体消去、固定/有限与共同增长、对数增益与固定幂次节省、
平均/几乎处处与指定端点/初始点、模型符号与实际算术系数。
反过来，也不能把限定范围内真实的算术结果一概称为玩具模型，或把一种方法的局部反例推广成全局不可能。

一句话：**用图记住研究对象和转移关系，用 handoff 与原始证据判断进度；每一项成果要能说明自己补的是哪一段。**
